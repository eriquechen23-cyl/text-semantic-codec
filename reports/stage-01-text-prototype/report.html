Stage 01 - Text Only Prototype

Text Semantic Codec 決策報告

本階段建立一個可執行、可測量、可解釋的文字語意通訊原型。重點不是先訓練大型模型，而是驗證 repo 架構、資料流、metric 與 demo 形式是否足以支援下一階段決策。

Prototype Scope

項目本階段決定
InputEnglish sentence
Semantic encoderRule-based concept extraction
BottleneckDiscrete codebook hash 或 continuous hashed vector
DecoderRule-based canonical reconstruction
MetricsExact match, BLEU, ROUGE-L, sentence similarity, compression ratio, semantic efficiency

Data Flow

Input Sentence
  -> Tokenizer
  -> Semantic Encoder
  -> Semantic Bottleneck
  -> Compact Semantic Code
  -> Semantic Decoder
  -> Recovered Sentence
  -> Metrics

Demo Command

python scripts/run_demo.py --text "The meeting has been postponed because of the heavy rain." --mode discrete --semantic-tokens 4 --codebook-size 256

這個 demo 會輸出 semantic concepts、semantic flags、semantic code、recovered sentence 與 metrics。

Decision

建議接受 Stage 01 作為文字語意通訊 prototype 的基線。下一階段應優先做 embedding-based semantic similarity 與 continuous bottleneck 實驗，而不是立刻加入 wireless channel，因為目前最關鍵的不確定性仍是「語意是否被保留」的量測方法。

Risks

風險影響下一步
Rule-based semantic vocabulary 太小遇到開放句型會重建粗糙加入 sentence embedding encoder
Similarity metric 還不是真模型語意可能高估或低估保真度導入 Sentence Transformer 或 OpenAI embedding 評估
Discrete codebook 目前是 hash，不是 learned codebook無法代表真正 VQ 訓練效果用 clustering 或 VQ-VAE 替代

Next Stage Checklist

  • 建立 embedding encoder baseline。
  • 比較 bottleneck dimensions: 128, 64, 32, 16。
  • 新增 semantic error categories: negation, time, quantity, location, named entity, intent。
  • 產生 Stage 02 report.html，記錄是否值得進入 learned codebook。
