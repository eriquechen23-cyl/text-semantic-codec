Stage 02 - Deployable Web Prototype

Render FastAPI + Angular 21 UI 決策報告

本階段把 Stage 01 CLI prototype 包成 HTTP API，並加入 Angular 21 standalone frontend，讓使用者可以在瀏覽器輸入文字、選擇 bottleneck 模式、取得 semantic code 與 recovered text。

Architecture

Angular UI
  -> POST /api/semantic/convert
  -> FastAPI backend
  -> semantic_text_codec package
  -> JSON response with code, reconstruction, metrics

Deployment Shape

ServicePlatformCommand
Backend APIRender Python Web Serviceuvicorn backend.main:app --host 0.0.0.0 --port $PORT
Frontend UIRender Static Sitecd frontend && npm ci && npm run build

Decision

建議採用雙服務部署：FastAPI 後端獨立部署，Angular 前端作為 static site。這讓 API 可以先穩定演進，前端也能快速替換 API URL 做 demo、測試或部署。

Risks And Follow-up

風險影響下一步
Angular 21 需要 Node 20+本機 Node 18 不能可靠建置Render 或本機升級 Node 後執行 npm ci/build
CORS 目前 prototype 預設允許所有來源正式服務安全性不足部署後把 ALLOWED_ORIGINS 改成 Angular Render 網址
Semantic codec 仍是 rule-based開放句型效果有限Stage 03 導入 embedding-based encoder
